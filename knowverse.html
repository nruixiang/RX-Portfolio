Project Overview

KnowVerse is a mobile game project developed in collaboration with the National Library Board (NLB). The goal was to create a game that encourages people to visit the library more often, while informing and encouraging them to use the resources and services NLB provides.

The challenge was to make library engagement genuinely fun through game mechanics — translating the value of physical library spaces into interactive, rewarding experiences players would return to.
